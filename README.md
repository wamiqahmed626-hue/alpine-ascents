# Alpine Ascents - Mountaineering Educational Field Guide

A responsive educational website created for the Aptech Semester 1 eProject.

## Overview
Alpine Ascents provides comprehensive information about mountaineering:
- History and landmark expeditions
- Climbing styles (Alpine, Expedition, Ski, Rock, Mixed)
- Technical techniques (ropework, crampons, ice axe, glacier travel)
- High-altitude camping, shelters, and campsite selection
- Objective and physiological mountain safety hazards
- Global alpine clubs and mountain geography
- Success stories of teamwork and courage
- Informative photograph gallery with image preview
- Latest equipment trends, climate impacts, and safety regulations
- Guidelines and equipment checklist
- User feedback form
- Bottom live tracker displaying current date, time, and detected geolocation

## Technologies Used
- HTML5 (Semantic elements and Geolocation API)
- CSS3 (Clean responsive design with solid color palette)
- JavaScript (Vanilla JS)
- Bootstrap 5 (CSS & JS bundle)

## How to Run
Open `index.html` located in the `Source Code` folder in any web browser.
